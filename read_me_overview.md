# Master's Thesis: GLIM Parameter Optimization & Volume Estimation

This repository contains the computational code for my Master's thesis, which focuses on optimizing and evaluating mobile LiDAR scanning within an ice tunnel environment.

The repository is divided into two main components:

* **Bayesian Parameter Optimization (`/code`):** Scripts and configurations used to find the most promising parameters for the GLIM (SLAM) framework, ensuring it operates reliably in the feature-poor and challenging conditions of an ice tunnel.
* **Volume Estimation (`/volume`):** Covers four different algorithmic implementations of volume estimators. This folder also contains the scripts used for the statistical evaluation, comparing measurements from a high-precision reference instrument against the mobile LiDAR sensor.

> **Note:** For detailed information on the code and usage examples, please refer to the dedicated `README.md` files located within each respective folder.
